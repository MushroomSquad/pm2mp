# pm2mp

**"Seamlessly control your pm2 processes with Python."**

**pm2mp** is a Python wrapper for the [pm2](http://pm2.keymetrics.io/) API that allows you to manage and run pm2 processes directly from your Python code.

## Description

The library wraps the main methods of the pm2 API, enabling you to:
- Manage pm2 processes
- Start, stop, and restart processes
- Retrieve status information and other essential details from pm2

## Installation

Install the library via `pip`:

```bash
pip install pm2mp
```

### Dependencies

The library requires the following packages:

- `annotated-types==0.7.0`
- `pydantic==2.10.6`
- `pydantic_core==2.27.2`
- `typing_extensions==4.12.2`

Additionally, ensure that your system has:
- [Python 3.10+](https://www.python.org/downloads/)
- [Node.js](https://nodejs.org/)
- [pm2](http://pm2.keymetrics.io/)
